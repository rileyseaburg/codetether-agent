# CodeTether Agent v4.7.5-dev.50 — draft prerelease

## Windows desktop stability

- Native desktop actions run through a persistent isolated worker with bounded
  requests/responses, deadlines, cancellation handling, and no automatic input replay.
- Checked screenshot allocations, RAII-managed GDI resources, bitmap deselection
  before extraction, and validation of complete scanline reads.
- Bounded image previews retain full-resolution captures separately and report
  explicit coordinate scaling. Physical keyboard input requires a foreground HWND.
- Payload-free worker lifecycle diagnostics help distinguish native failures
  without treating an unexplained process exit as proven OOM.

## Windows installation and OCR

- Native Rust WinRT OCR and HWND-targeted shadow mouse/keyboard support.
- Actual per-user MSI setup packages, alongside executable and setup ZIP assets.
- Local staging for NAS/UNC launches; corrected deferred MSI action sequencing.
- Original Vault address/token configuration restored with hidden token input and
  a dialog fallback. Existing credentials are preserved when configuration is declined.
- Readiness probes run without agent telemetry/provider initialization and capture
  native stdout/stderr independently, avoiding PowerShell 5.1 warning-as-error failures.
- MSI authoring is checked through real tables and extracted payload hashes before
  promotion. Release jobs now include MSI assets.

## Editor diagnostics

- Correct language identifiers for JSX/TSX documents and pre-approval diagnostic
  regressions, so syntax errors are checked using the intended language mode.

## Verification and release status

This is a draft prerelease, not a claim of successful deployment or Windows stress
testing. Focused local tests, worker subprocess tests, Windows cross-builds, and
MSI artifact inspection are the available evidence. CI owns the full serial test
gate and Linux/macOS/Windows release builds; those results must be checked before
publishing. Windows MSI/UAC/OCR and application-specific interaction are not
universally established by mocked tests or cross-compilation.

The MSI and hosted macOS artifacts are not publisher-signed. Windows signing and
organization policies remain authoritative. Shadow-message queue acceptance does
not prove application effects. Tokens retain the original Windows user-environment
persistence behavior; hidden entry is not encrypted credential storage.
